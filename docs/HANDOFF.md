### 지난 세션(2026-10-29)에 한 일
- 그림을 투명 배경 PNG로 바꿨다. 이미지 도구가 진짜 투명 PNG를 준다(채팅 미리보기엔 갈색 배경처럼 보이지만 파일 알파는 0). 흰 배경 지우기(clean_halo.py)로는 머리카락 사이 흰 조각이 다 안 빠져 접었다.
  - 여울 SD 기본 8장, 낚시 8장(모두 빈 주먹), 여울 일러스트 다섯 장, 세라 표정 여섯 장을 바꿨다.
  - 일러스트: yeoul-eat(숟가락, 프롤로그 무미 장면·1장 끝 마지막 대사), yeoul-serve, yeoul-hands 교체. 새 yeoul-salty-tear(젓가락 눈물, 프롤로그 첫 짠맛 두 장면), 새 yeoul-rod-broken(프롤로그 창고 장면, 표정 rodBroken).
- 낚시 포즈: 손에 대가 없다. 게임이 주먹 자리(poses.json grip)에 대 밑동+릴 그림(gear/butt-N, 릴 단계)을 쥐여 주고 그 위로 낚싯대 몸통 그림(gear/blank-N, 대 단계)을 휘는 곡선을 따라 띠로 붙인다(FishingField.PaintBlank). 원줄은 릴 스풀(gearlook.json reelSpool)에서 나와 그림 속 고리 눈(gearlook.json blanks.guides)을 지나 끝까지. 원줄을 먼저 그려서 대·고리에 가린 데는 숨는다.
- 앉기·입질: 다리가 바닥에 안 닿아도 되는 의자 높이 포즈. 엉덩이 아랫선을 seat 로 잡아 가진 의자(chair-back-N)를 맞춘다. 의자 1·3·5·7·10단계 사진으로 확인.
- 감기·버티기: 실제 버티는 법을 조사해 다시 뽑았다(손잡이 끝을 배에, 대는 45~60도로 세움, 무릎 굽혀 뒤로 기댐). 버틸 때 대가 물고기를 바로 겨누지 않게 돌림을 0.85→0.4로 줄였다.
- 맛이 돌아오는 규칙(B안, 사용자 결정): 짠맛은 내 손으로 낚은 물고기에서, 다른 맛은 그 물고기를 누군가와 함께 먹을 때 돌아온다. 게임 수치(어종 수 조건)는 그대로. 1장 끝 대사와 이야기 화면을 이에 맞췄다(할머니가 "여울이 낚아 온 볼락"을 구워 마주 앉는다). 웹 버전 글은 그대로.
- 사진 모드 체험 판 추가: --demo=chair1~10, --demo=rod1~10. 워크플로 사진 fishing-chairN-wait/-bite, fishing-rodN-reel/-wait.

## 확정된 결정
- Godot 4.7.2 .NET(C#), Compatibility, 세로 1080×1920. 돈 드는 것 금지. 규칙은 core/, 화면은 godot/scripts, 수치와 글은 godot/data/*.json.
- 새 그림 프롬프트는 투명 배경 판(ART_PROMPTS SD 7)으로 준다. 시트 배경 #EDEDED 판은 옛 방식.
- 낚시 포즈 그림은 빈 주먹. 대·릴·원줄은 게임이 그린다. 낚싯대는 대 단계마다 다른 그림, 릴은 릴 단계마다 다른 그림.
- 캠핑 의자에 앉아 텀블러를 든 여울 일러스트는 쓸 곳이 안 맞아 보류(레포에 없음, 원본은 사용자에게 있다).
- 그림 역할: 움직이는 캐릭터는 SD 2~2.5등신, 대화는 일러스트, 감정 순간은 9:16 컷신. SD 걷기 그림은 오른쪽을 본다.

## 사용자 선호
- 그림은 레포에 넣기 전에 한 장씩 검수 받는다(지금 그림과 새 그림을 어두운 바탕에 나란히 놓은 비교 그림을 보낸다). 승인 뒤에 넣는다. 실제 화면 확인이 필요하면 시험 빌드를 올려 CI 사진을 확대해서 보여 준다.
- 낚시처럼 실제 모습이 중요한 건 먼저 조사해서 자연스럽게, 출처를 붙인다.
- 그림 프롬프트는 복붙용 코드 블록 하나씩, 첨부할 그림이 있으면 파일로 같이 보낸다. "무엇을 첨부하는지"를 쉽게 설명한다(지난번 "대 손잡이·릴 시트"가 뭔지 물었다).
- 사용자는 폰으로 해 보고 사진으로 의견을 준다. 받으면 바로 반영한다.

## 환경 제약
- 컨테이너는 새로 만들어진다. 다시 설치: apt-get update 후 apt-get install -y dotnet-sdk-8.0, pip install scipy.
- 고닷은 여기서 실행 못 한다. C# 점검: dotnet build godot/Hanjeopsi.csproj -p:HanjeopsiNet8=true. 화면은 CI 사진으로 본다(git fetch origin ci-build, BUILD.txt 의 커밋 해시 확인).
- CI 를 기다릴 때는 git ls-remote origin ci-build 가 바뀔 때까지 백그라운드로 돌린다. 포그라운드 sleep 금지.
- 사용자가 준 원본 시트는 세션이 끝나면 없어진다(레포에 넣지 않는 규칙). 잘라 넣은 그림만 레포에 있다.
