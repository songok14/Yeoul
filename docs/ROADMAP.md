# 여울호 · 로드맵

원칙: **재미 확인이 먼저.** 그래픽은 Phaser Graphics와 코드로 찍은 임시 도트로 시작하고, 루프가 재미있다는 확인이 된 뒤에 그림을 바꾼다. 돈이 드는 도구나 서비스는 쓰지 않는다.

## 0단계 · MVP 1장 물비늘포 ✅ (v0.1)

- [x] Phaser 3.90 + TypeScript + Vite, Galmuri11 도트 폰트, 세로 450×800 FIT
- [x] 프롤로그 (타자기 텍스트, 튜토리얼 낚시, 미각 0단계 간 맞추기, 고양이 등장)
- [x] 마을 허브 (방파제, 위판장, 여울호, 미끼가게, 여울식당, 수첩)
- [x] 낚시 미니게임 (방향, 파워 게이지, 속임 입질, 챔질, 텐션 릴링, 고등어 힌트)
- [x] 어종 5종 (볼락, 고등어, 노래미, 학공치, 감성돔)
- [x] 시간 슬롯 (새벽·아침·낮·저녁), 날 바뀜 시 신선도 감소와 시세 변동
- [x] 위판장 경매 판매, 납품 의뢰
- [x] 푸드트럭 요리 (간 맞추기, 맛별 손님 반응, 미각에 따른 정답 구간 공개)
- [x] 미각 회복 1~3단계 (짠맛 · 단맛 · 감칠맛)
- [x] 장비 업그레이드 (낚싯대 · 릴 · 소품 각 2단계), 미끼 구매
- [x] 30일 300만 원 상환 목표, 클리어 / 차압 결말, 조황일지 1장
- [x] localStorage 세이브, Playwright 스크린샷 · 자동 플레이 점검
