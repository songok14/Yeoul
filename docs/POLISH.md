새 기능은 잠시 멈추고 화면마다 어색한 점을 하나씩 지운다. 폰 사진을 받으면 `docs/feedback/<날짜>/`에 줄여 넣고 아래 해당 화면에 줄을 붙인다.

- 우선순위(2026-10-26 사용자): **낚시 → 트럭 → 마을 → 위판장·상점** 순서. 수첩·타이틀·이야기는 그다음.
